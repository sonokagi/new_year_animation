# 年賀状向け干支アニメーション

円環上に配置された 12 個の干支が回転する、p5.js 製のアニメーションです。画面をクリックまたはタップすることで、翌年の干支へと進みます。

## 実行方法

1. このリポジトリをダウンロードまたはクローンします。
2. `index.html` を任意のブラウザで開くだけで動作します。

## 使用技術

- **[p5.js](https://p5js.org/)**: クリエイティブコーディング用ライブラリ

## 開発環境

本プロジェクトは、AI コーディングアシスタント **Antigravity** を使用して開発しています。
リポジトリ内の `.agent` フォルダには、開発ポリシーや初期化用ワークフローなど、AI エージェントがプロジェクト固有のルールを遵守するための設定が含まれています。

- **/init**: 作業開始時に実行し、本プロジェクト固有の開発方針をエージェントに適用します。
- **/new_topic**: 既存の議論をクリアし、新しいトピックでの議論をスムーズに開始します。
