# 年賀状向け干支アニメーション

円環上に配置された 12 個の干支が回転する、p5.js 製のアニメーションです。画面をクリックまたはタップすることで、翌年の干支へと進みます。

## 実行方法

1. このリポジトリをダウンロードまたはクローンします。
2. `index.html` を任意のブラウザで開くだけで動作します。

## 使用技術

- **[p5.js](https://p5js.org/)**: クリエイティブコーディング用ライブラリ

## 開発環境

本プロジェクトは、AI コーディングアシスタント **Antigravity** を使用して開発しています。「Simplicity First（シンプルさ優先）」の原則に基づき、保守しやすく読みやすいコード構成を維持しています。

リポジトリ内の `.agent` フォルダには、AI エージェントがプロジェクト固有のルールを遵守するための設定（開発ポリシーやワークフロー）が含まれています。

### 開発用スラッシュコマンド

AI エージェントに対する指示として、以下のスラッシュコマンドを使用できます：

- **`/init`**: プロジェクト固有の開発方針を再読込し、作業を再開します。
- **`/plan`**: 新しいタスクの「実装計画（プラン）」を作成させます。
- **`/ok`**: 万能の「次に進め」コマンド。プランの承認や実装完了の確認に使用します。
- **`/exec`**: 承認されたプランに基づき、実装・修正を実行させます。
- **`/commit`**: 実装完了後の Git コミットを実行させます。
- **`/new_topic`**: 既存の議論をクリアし、新しいトピックでの議論を開始します。
